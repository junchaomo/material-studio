# 六类页面布局核对（2026-10-12）

以用户提供的六类页面表为布局依据，继续沿用浅色外壳、深色画布和蓝色主操作。

| 页面 | 地址 | 布局 |
|---|---|---|
| 首页 | `/` | 顶部导航、工作台产品示意、两个独立功能入口、精选案例 |
| 效果图工作台 | `/app/projects/:id/studio` | 左侧工具与素材、中间画布、右侧模型参数、整页底部版本栏 |
| 材质提取工作台 | `/app/projects/:id/extract` | 顶部五步流程、左侧识别清单、中间原图和选区、右侧模型参数与结果预览 |
| 项目库 | `/app` | 项目卡片进入详情；详情分效果图、方案版本、材质库 |
| 案例社区 | `/app/community` | 搜索、分类、案例卡片；详情地址 `/app/community/:id` |
| 个人中心 | `/app/settings` | 侧边设置导航、账户信息、用量与订阅、反馈和安全 |

效果图与材质提取独立入口分别为 `/app/studio` 与 `/app/extract`，先选项目，创建项目后保留入口意图。项目详情三个地址分别为 `/app/projects/:id`、`/versions`、`/materials`。

现金付费、自动续费保持暂停；现有会员、用量和积分继续展示。社区分类在案例说明中使用明确的分类标签，旧案例显示“未分类”；不根据图片猜测分类。筛选覆盖搜索得到的全部分页结果。

本地浏览器核对了两工作台、项目详情、个人中心、首页和社区空状态，未创建假案例或调用收费模型。首页另检查了手机宽度。没有已发布案例，真实案例详情及交易流程本轮未执行。

## 任务可靠性补充

不确定是否成功的材质任务提交编号保存在当前浏览器会话中，服务器确认后清理。识别轮次按初次提交时间排列，旧轮重试不覆盖最新轮；清单可查看历史轮次。

处理服务在模型返回后立即保存 AES-GCM 加密恢复副本，输入和任务编号校验通过才可恢复。同一处理机的显式重试优先恢复结果，不再次调用模型；保存失败会保留副本，数据库完成后清理。电脑停止时队列继续保留，云端网页不承担长时间模型处理。

本轮恢复了此前因自动审批额度不足而未能启动的本机处理服务。模型质量仍待另外验收，本轮布局通过不代表贴图质量通过。
