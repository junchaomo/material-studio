# 启明星统一工作台

依据《启明星_AI专业效果图SaaS_MVP技术方案_V1.4_Vercel精简版》推进。先验收工作台，再优化材质提取质量。

## 本次可运行范围

- Next.js App Router、TypeScript、React Konva、TanStack Query、Zustand、Zod。
- `/` 未登录首页，`/auth/login` 与 `/auth/signup` 使用原 Supabase 账号。
- `/app` 私有项目，`/app/projects/:id/studio` 素材、画布、模板参数、版本四区布局。
- 私有云端素材、签名上传和下载，项目与存储使用成员权限隔离。
- 输出优先 PNG；过大的 PNG 尝试保存为原尺寸无损 WebP，以适配存储平台单文件限制，不通过缩放或有损压缩规避限制。
- Mock 多结果生成、蒙版局部合成、父版本关联、原图对比和下载。白色蒙版范围外保持源图解码后的像素不变。
- 任务幂等创建与 outbox 同一事务。并发处理通过 queued → running 条件更新认领。
- 材质模块通过适配入口关联项目与图片，已有浏览器材质数据保留；算法优化暂停。
- 原积分、个人中心、本地管理后台保留。支付保持关闭。

## 明确的阶段边界

- Mock 是确定性的本地图片调整与合成，不是根据提示词理解设计的真实 AI 生图；参考图仅保存与关联，不参与 Mock 图片生成。
- 当前 Mock 在浏览器请求服务器执行后完成，任务持久化在 Supabase；尚未接入 Inngest 云端消费者。关闭页面前未发送执行请求的任务会在重新打开后继续。运行中的请求若服务中断，需要核对任务，不自动重复处理。
- 真实国内模型效果图适配器、预算计量、云端任务重试与对账仍是后续接入项。当前不会调用真实模型。
- 沿用用户之前取消上传大小限制的要求，不设置应用层文件大小上限；仍受 Supabase 平台自身上传限制影响。
- 材质资源目前仍保存在当前浏览器，通过显式关联从私有云项目导入来源图；尚未将历史本地材质自动搬入云端。
- 个人资料、账户权益、积分明细与意见反馈采用统一工作台页面；保留原有后端与权益规则。案例社区当前通过适配入口嵌入，尚未重写其交互。

## 部署与验证

`npm run build` 完成 Next.js 生产构建；`npm test` 验证旧功能和新增像素保护。

`supabase/workbench-v1.sql` 已通过 Supabase migration 应用，13 张表开启 RLS，`qmx-assets` 为私有桶。所有新接口使用用户会话与 RLS，不使用客户端可见的服务角色密钥。权限隔离的事务验证全部回滚，不留下验证项目。

Vercel 使用 `vercel.json` 的 Next.js 设置。保持原服务器 `SUPABASE_URL` 和 `SUPABASE_PUBLISHABLE_KEY`，不需要把密钥放入前端环境变量。

默认 `REAL_AI_ENABLED` 未设置或不是 `true` 时，不允许旧材质 API 发起真实识别或重建。`COMMERCIAL_PAYMENTS_ENABLED` 保持 `false`。


## 工作台材质提取

项目页的「材质提取」与效果图工作台共享来源素材。左侧选择来源，顶部提供 AI 六区识别、手动提取、需求清单、材质库、检查与导出。原材质引擎通过同源消息协议接入，编辑器在工作台内部展开；不要求用户手动关联或跳转旧站。保存后同步显示材质数量及确认数。

材质 AI 使用现有模型与账户权限；`MATERIAL_AI_ENABLED=false` 可暂停识别和重建。效果图生成仍使用 Mock。打开识别界面不会发出收费请求；需要用户点击六区识别按钮后执行。未对提取算法作质量改造，人工确认规则保留。
