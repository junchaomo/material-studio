# SAM 3 网关（已下线）

本机版本不包含 SAM 3 分割网关，模型协议白名单里也没有 `sam3`：只保留 `dashscope`、`openai`、`volcengine` 三种国内协议。

此前基于海外托管服务的 SAM 3 预设、网关契约、调用说明与接口地址，已随国外模型一并移除。分割能力请使用本机 Python 服务（默认 `http://127.0.0.1:4192`）的 `presegment` 操作：它返回黑白 Mask 与超像素统计，全程不调用海外接口。

若将来需要重新接入分割模型，请在国内厂商的兼容接口上实现，并按 `MODEL-CONFIGURATION.md` 的白名单规则登记。
